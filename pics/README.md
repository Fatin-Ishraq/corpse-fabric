# Screenshot sources

The PNG screenshots in this directory were downloaded from the public description of the official [Corpse project](https://www.curseforge.com/minecraft/mc-mods/corpse) by Max Henkel.

They are included with attribution for preparation and review of the unofficial Fabric port listing. They are not original screenshots of this Fabric implementation. The preferred release-page assets are replacement screenshots captured directly from the Fabric builds.

`6x9lhS5.htm` is an incomplete image-download page and is intentionally not part of the published assets.
